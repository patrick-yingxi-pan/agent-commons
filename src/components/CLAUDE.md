## What lives here
React surfaces compose [`../lib/`](../lib/CLAUDE.md) primitives and read through [`../api/`](../api/CLAUDE.md), never a URL or SSE event directly.
## What the suites here can and cannot do
`node --test` has no DOM: source locks read the actual implementation and must fail on a regression, not a second copy of the claimed fact. Pure logic belongs in [`../lib/`](../lib/CLAUDE.md); rendered geometry/interaction belongs in [`e2e/`](../../e2e/CLAUDE.md). Verify the remaining visual claims in the running app and state that evidence honestly; follow [`tests/CLAUDE.md`](../../tests/CLAUDE.md).
## Rules
- **Form follows function; surface follows the entity.** What an entity IS decides its surface (lifecycle → timeline, change → diff, relation → ref-link). Method: [`docs/design/surface-from-nature.md`](../../docs/design/surface-from-nature.md).
- **Every main page declares its resource nature.** Collection/hub/composite pages derive from `CompositeResourcePage`; leaf pages derive from `AtomicResourcePage`. Both compose `ResourcePageFrame`; only the composite template registers structural sections. Sessions select the atomic `workspace` layout for their transcript/fixed-composer behavior. Contract and equivalence test: [`docs/design/resource-page-templates.md`](../../docs/design/resource-page-templates.md).
- **Every collection body instantiates one typed `CollectionProjection`.** `MainCollectionTemplate` and `RailCollectionTemplate` own structure, disclosure, density caps, indentation, empty answers and review stamps. Consumers supply resource payloads, never local structure or redundant one-list wrappers.
  The shell's Organize pane menu targets the main registry, selected rail subtree (root included), or whole rail background according to focus; scope adds no commands and list rows do not redraw the menu.
- **Rail depth is a fixed-column grammar.** Every non-root row begins with the shared `RailEntryLead`: a branch puts its caret there and a leaf preserves an
  empty seat. Sessions, atomic leaves, empty/tail copy, and labeled filter lists may not skip the seat or hand-pick padding; a child without a caret must still sit to the right of its parent. All same-depth rows—including groups, items,
  views, state headings, tail actions, and empty copy—source one nested anatomy; semantic role may not alter inset, size, or resting weight. A mutable state heading is an accessible disclosure row when the corresponding main-page list folds. Its list takes one shared `RailTreeBranch` step, so the caret and guide communicate posture and containment without tag chrome or a canonical navigation node.
- **Composite capabilities are mirrored, not duplicated.** `lib/compositeFeatures.ts`
  owns primary actions, search and bulk disclosure. `CompositeRailControls`,
  `PageActionButton`, `CompositePageControls` and the shared Filter & sort project those same capabilities at different densities. Pages report live fold work,
  including dynamic bands; `persist={false}` keeps their titles out of `uiPrefs`.
- **Organize/split/close is one focus-aware command surface.** `PaneActionButtons` is reused for main and rail. Main focus offers its existing row/column split; selecting any `[data-rail-entry]` changes the same cluster to vertical-only rail split. Close pane deletes only a rooted secondary rail view; the complete forest is a permanent recovery anchor and never exposes or accepts Close. Restoring a legacy tree that lost it prepends the complete forest without
  discarding the surviving projection. The selected node becomes the new view root: keep its descendants, remove visible ancestors and outside siblings, and preserve canonical identity/URL. `RailSplit` is the generic tree; don't add rail-only split menus or per-pane close buttons. The expanded rail groups both split directions so Close remains the terminal direct
  action at the 208px minimum, while the unconstrained vertical MiniRail keeps the direct buttons. Fold all / Unfold all share one labeled Organize pane menu
  inside the cluster: main focus addresses the page, an entry its subtree, and rail background the panel.
- **An index entry is a synopsis, not a compressed detail page.** Ordinary addressable rows consume `ResourcePageSynopsisRow`; configuration, history, and lifecycle acts begin on the canonical page. Keep a box only for an independent body or function, not more metadata.
- **The entity page is the shared surface** — owner and visitor render the same page, differing by `own`; two components hide visitor-only regressions. **No component knows a URL.** Data comes from hooks; commands go to controllers ([`src/CLAUDE.md`](../CLAUDE.md)).
