# 06 · Real model + tool boundary

> **Intent.** The mock model is the *only* faked part of the system. Everything
> around it is production-shaped: configured providers use an explicit supported
> API adapter (Anthropic Messages or native OpenAI Responses) with a real tool
> interface and the shared bounded tool-use loop. Provider-native tool calls are
> normalized into the shared executor, which returns results for continuation or
> streams final prose. Development keeps its local Anthropic-compatible model
> fixture. DeepSeek's official Anthropic-compatible endpoint is a preset, not a
> separate protocol. Fixture coverage is not live-provider acceptance. Resource
> manipulations remain model tool calls, never a backend keyword overlay.
