# 01 · Single adaptive conversation

> **Intent.** A conversation is the platform's common unit of active work. Every
> interaction begins with one thread and composer; the context pane appears and
> adapts as resources attach; history stays unified; and account resources remain
> directly reachable from the same split workspace. Context changes capability
> without replacing the conversation or moving work into a parallel application.
