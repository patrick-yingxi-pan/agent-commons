# desktop/ — Electron shell context
## Scope
Owns Electron lifecycle, trusted windows, OS user-data placement, user-mediated native selection, OS-encrypted provider/MCP credentials and packaging. Product behavior and MCP inspection/execution stay in the shared UI/server contract; combined real-service/native acceptance remains a separate release gate.

Read [`../server/CLAUDE.md`](../server/CLAUDE.md) for the supervised runtime; [`../src/CLAUDE.md`](../src/CLAUDE.md) for renderer setup.
