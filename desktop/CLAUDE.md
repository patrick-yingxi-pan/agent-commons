# desktop/ — Electron shell context
## Scope

Owns the near-term native shell. Product behavior stays in the shared UI/server contract; the shell owns process lifecycle, trusted-window policy, OS user-data placement, user-mediated native selection, the OS-encrypted
provider-credential adapter, the MCP credential vault/IPC lifecycle, and packaging.
MCP inspection and approved execution use the shared backend; combined real-service/native acceptance remains a separate release gate.

## Read path

Read [`../server/CLAUDE.md`](../server/CLAUDE.md) when changing the supervised
runtime profile or utility-process contract, and [`../src/CLAUDE.md`](../src/CLAUDE.md)
when changing the renderer-facing bridge or setup UI.

## Verification

Profile tests cover mode and real macOS ACL refusal without repair, absent ACLs,
deny-only and owner-only ACLs, inherited grants, failed inspection, identity
changes and broad-path refusal. Packaged refusal acceptance uses only generated
profiles; its excluded inspector harness fixtures the early error-dialog response,
not admission, file access or exit. Ordinary startup/relaunch separately preserves
a private profile and exact sentinel. The startup-order lock remains separate:
later MCP reconciliation also tightens mode, so post-readiness inspection alone
cannot prove early admission. Scope and remaining limits are recorded in the
[production plan](../docs/production-plan.md); no user profile is a test fixture.

The packaged restore phase drives Customize's actual backup/restore controls
against its own generated profile. Distinct before/after Documents, Sheets,
Slides and conversations prove replacement; restoring the safety copy proves
recovery of the newer work. Picker/confirmation cancellation performs neither
replacement nor safety-copy creation. A malformed managed snapshot retains
current work and reports failure before an independent restart. The pre-backup
provider vault, device authentication root and personal token remain intact.
Only dialog answers and the relaunch spawn are controlled by the test; the real
shell exits, and a new packaged process loads the restored SQLite state. This
does not prove OS-managed automatic relaunch, actual dialog interaction, recovery
of credentials rotated/deleted since the backup, or OS-backed encryption under
Playwright's test launcher. Ordinary executable smoke remains the real OS-storage
gate. An isolated ASAR mutation that acknowledged restore without writing it
failed the exact post-restart workspace assertion before acceptance.
